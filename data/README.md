# Local project data

Client workbooks and generated analysis tables are stored in a separate local directory. This repository supplies the analytical code, data definitions, and original client-report exhibits.

The local importer reads the master store roster, monthly sales, launch metadata, and final cumulative-outcome workbook. It creates the five canonical tables defined in the [data dictionary](../docs/data-dictionary.md).

Required source files, conversion steps, and execution commands are listed in the [execution guide](../docs/reproducibility.md#local-client-materials).
