# Attribution and data use

This repository documents a UIUC BADM550 client analytics project. It includes the original analysis notebooks, client-report exhibits, and supplementary implementation code.

The MIT license covers newly authored supplementary code and documentation to the extent of the contributor's rights. Original course materials, client records, AWG trademarks, project notebooks, presentations, and presentation-chart excerpts retain their respective rights. Complete client presentations and archived code are included with attribution; client workbooks and source-file backups are preserved locally.

Archived notebook copies retain source code and cell order with saved outputs cleared. Active execution editions have a documented change record. Their manifest records archive and active code hashes. Client-report exhibits retain their original assets and include slide-level provenance, based on the project owner's understanding of report-sharing permissions.

Documentation and supplementary implementation work were prepared with AI assistance. The project deliverables and design decisions document the original analysis and the later implementation enhancements.
